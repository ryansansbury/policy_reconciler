# People's decisions become rules

## The decision

Where the experts disagree a person decides each group once and writes down the reason. The decision becomes a rule code applies to every pair in the group, a new version of the answer key, and a test.

## Why

A disagreement between experts isn't a question for a model. Writing the decision down means the same question is never asked twice, and the test keeps code from drifting away from it.

## What it costs

Someone has to own the decisions, and they're versioned so a later change is visible. The page shows the experts' agreement before and after.
